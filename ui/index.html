Package mod

  

    

      
      
      
      
      
      
      
      
      
      
      
      
    

    

    
Amalgam works out which game the mod is for from how its files are laid out, leaves out work files like .blend and .psd, checks for that game's common mistakes, does the processing the game needs (archives, converted files, installer files) and builds a .zip in the _packages folder that the game's usual mod manager installs.
